# `@compasscms/contracts`

[![npm version](https://img.shields.io/npm/v/%40compasscms%2Fcontracts?logo=npm)](https://www.npmjs.com/package/@compasscms/contracts)
[![npm license](https://img.shields.io/npm/l/%40compasscms%2Fcontracts)](https://www.npmjs.com/package/@compasscms/contracts)

Shared TypeScript types and the versioned OpenAPI contract for Compass API
consumers and backend implementations.

Licensed under the GNU Affero General Public License v3.0 only. See [LICENSE](./LICENSE).

```ts
import type { Collection, FieldDefinition, Post } from "@compasscms/contracts";
```

The machine-readable specification is available at
`@compasscms/contracts/openapi.json`. The human-readable API contract is in
[`API-CONTRACT.md`](./API-CONTRACT.md).
